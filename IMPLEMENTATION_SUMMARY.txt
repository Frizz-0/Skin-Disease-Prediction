🎯 TECHNICAL IMPLEMENTATION
█████████████████████████████████████████████████████████████████████████████

GRAD-CAM ALGORITHM:
┌─────────────────────────────────────────────────────────────────────┐
│ 1. Forward Pass:  Input → EfficientNet backbone → Disease/Skin head │
│ 2. Detect Class:  Get logits for target disease class               │
│ 3. Backward Pass: Compute gradients w.r.t. backbone features        │
│ 4. Compute Map:   Weight activations by gradients                   │
│           weights = avg_pool(gradients)                             │
│           heatmap = ReLU(sum(weights × activations))                │
│ 5. Normalize:     Scale heatmap to [0, 1]                           │
│ 6. Colorize:      Apply OpenCV JET colormap                         │
│ 7. Blend:         Overlay on original image (50% alpha)             │
└─────────────────────────────────────────────────────────────────────┘

MODEL ARCHITECTURE:
┌─────────────────────────────────────────────────────────────────────┐
│ Input (224×224×3)                                                   │
│         ↓                                                            │
│ EfficientNet-B0 Backbone (Feature Extraction)                       │
│         ├─→ [Grad-CAM Target Layer: features[-1]]                   │
│         ↓                                                            │
│   Dense Features                                                    │
│     ├→ Disease Head: Linear(512) → ReLU → Linear(114 classes)      │
│     └→ Skin Type Head: Linear(256) → ReLU → Linear(6 types)        │
└─────────────────────────────────────────────────────────────────────┘

DATA FLOW (Frontend ↔ Backend):
┌──────────────────────────────────────────────────────────────────────┐
│ 1. User captures image from camera                                   │
│ 2. Frontend POST /predict                                            │
│    → Backend infers disease & skin type                              │
│    ← Returns predictions with confidence scores                      │
│ 3. Frontend POST /gradcam (image + disease class index)             │
│    → Backend computes gradients                                      │
│    → Extracts activations and gradients from hooks                   │
│    → Generates heatmap                                               │
│    ← Returns base64 encoded visualization                            │
│ 4. Frontend displays Grad-CAM in UI                                  │
└──────────────────────────────────────────────────────────────────────┘

→ pip install -r requirements.txt
→ Check if port 8000 is free

Frontend can't reach backend?
